## RealWaste Dataset

Dataset: RealWaste
Authors: Sam Single, Saeid Iranmanesh, Raad Raad
Year: 2023

Source:
https://archive.ics.uci.edu/dataset/908/realwaste

License: Creative Commons Attribution 4.0 International (CC BY 4.0)
https://creativecommons.org/licenses/by/4.0/

Modifications:
Images resized and processed for machine learning.
The dataset was used to train an image classification model
for the EcoScan application.

Original publication:
RealWaste: A Novel Real-Life Data Set for Landfill
Waste Classification Using Deep Learning.
